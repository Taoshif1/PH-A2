# PH-A2 — Faugei Flower Shop

A responsive flower-shop landing page built from scratch with HTML and CSS as a frontend practice assignment.

## Live demo

https://taoshif1.github.io/PH-A2/

## Highlights

- Responsive navigation and cart presentation
- Hero/banner section
- Product/plant card grid
- Plant-lover feature section
- Promotional deals layout
- Newsletter/join section
- Responsive footer
- Mobile and tablet breakpoints

## Tech stack

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Run locally

```bash
git clone https://github.com/Taoshif1/PH-A2.git
cd PH-A2
```

Open `index.html` in a browser.

## Project status

Frontend learning project focused on layout, grid/flexbox, responsiveness and translating a visual design into code.
